# A Comprehensive Review of Cryptographic Techniques in Federated Learning for Secure Data

## Project Overview
This project explores techniques for protecting data privacy and security in federated learning. Federated learning allows multiple clients to train a shared machine learning model without directly sharing their raw data.

## Objectives
- Understand federated learning and data privacy.
- Study cryptographic techniques used to secure data and model updates.
- Explore approaches to secure collaborative machine learning.

## Technologies
- Python
- HTML and CSS
- JavaScript
- CSV datasets

## Project Structure
- `DOCUMENTS/` — project report and presentation.
- `SOURCE CODE/` — application source code, algorithms, datasets, templates and static files.

## Getting Started
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the `SOURCE CODE` folder.
4. Install the dependencies required by the application.
5. Run the application using the instructions provided by its source code and dependencies.
